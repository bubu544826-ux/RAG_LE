# Frontend Changes

## Theme toggle

- Added an accessible, keyboard-navigable sun/moon toggle in the top-right corner.
- Added dark and light theme palettes using CSS custom properties on the root `data-theme` attribute.
- Added smooth color, border, shadow, and icon transitions with reduced-motion support.
- Added browser-local theme persistence so the selected appearance is restored on future visits.
- Updated message, input, sidebar, feedback, and code-block colors for accessible contrast in both themes.
